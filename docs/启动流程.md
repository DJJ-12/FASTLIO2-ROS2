第三 步：终端2 = 启动建图节点

ros2 launch pgo pgo_launch.py
检查激光里程计节点fastlio2 是否正常发布数据： ros2 topic hz /fastlio2/lio_odom  

第四步： 终端3  = 请求保存地图服务
source /opt/ros/humble-agv/setup.bash

ros2 service call /pgo/save_maps interface/srv/SaveMaps \
    "{file_path: '/mnt/ros2/maps', save_patches: true}"

可选（在 Ubuntu 虚拟机里用 RViz 显示 map.pcd）
在虚拟机终端执行挂载命令（假设盒子IP是 192.168.1.32）：scp -r root@192.168.1.32:/mnt/ros2/maps ~/
 输入盒子密码。完成后你本地会有：~/maps/map.pcd
然后你在虚拟机中运行命令
ros2 run pcl_ros pcd_to_pointcloud \
  --ros-args \
  -p file_name:=/home/mt/maps/map.pcd \
  -p interval:=1.0 \
  -p frame_id:=map

再在终端2 中运行rviz2 ,订阅/cloud_pcd，别忘了把坐标系改成base_link  

第五步：定位
终端1：启动节点

ros2 launch localizer localizer_launch.py
 
终端2：触发重定位（加载地图）
检查激光里程计节点fastlio2 是否正常发布数据： ros2 topic hz /fastlio2/lio_odom  

ros2 service call /localizer/relocalize interface/srv/Relocalize \
"{pcd_path: '/mnt/ros2/maps/map.pcd', x: 0.0, y: 0.0, z: 0.0, yaw: 0.0, roll: 0.0, pitch: 0.0}"

ros2 service call /localizer/relocalize_check interface/srv/IsValid "{}"
